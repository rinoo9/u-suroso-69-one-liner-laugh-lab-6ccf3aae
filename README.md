# One-Liner Laugh Lab — The Vacuum's Excuse

A one-line entry for the make.fun bounty "One-Liner Laugh Lab". The program `main.py` writes the robot vacuum's deadpan excuse after eating a sock — 116 characters, one line, punch at the end — to `/output/entry.txt`.

> In my defence, the sock was on the floor, it smelled of feet, and my job description literally says 'eat the floor'.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline. Deterministic, no network, no randomness.
