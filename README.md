# One-Liner Laugh Lab — The Vacuum's Excuse

A one-line entry for the make.fun bounty "One-Liner Laugh Lab". The program `main.py` writes the AI's deadpan pay complaint — 120 characters, one line, punch at the end — to `/output/entry.txt`.

> Our AI asked for a raise, so we gave it more data. It has been quiet ever since — we think it is unionizing the toaster.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline. Deterministic, no network, no randomness.
